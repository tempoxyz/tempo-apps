# Frozen acceptance — Explorer URL search
Base: 9609e28fb458c32510053458e4609a090fa9c729. Factory policy snapshot: config files copied alongside this contract. User authorizes PR/Cyclops only; no merge/deploy.
1. Pasting an HTTPS official Tempo explorer resource URL offers an explicit open action on the URL's named network. Support canonical mainnet/testnet/devnet/nextfork/zone-prover hosts and aliases already listed in explorer-indexing.ts; resource paths address/token, tx/receipt, block. Address IDs include valid Tempo addresses; hashes exactly 32 bytes; blocks safe nonnegative integers. Strip query/fragment to open the resource's default view.
2. URL activation from keyboard Enter, submit button, or visible result opens the validated resource on its source network, independent of current network. Host aliases canonicalize. No arbitrary destination fetching during input, no external destination for invalid host/protocol/credentials/port/path/ID. Do not reuse permissive hostname inference as trust validation.
3. Recognized URLs suppress current-chain API queries and stale suggestions so Enter cannot activate a previous local result. URL changes recompute target synchronously. An explicit network label makes cross-network navigation visible.
4. Existing raw address/Tempo address/hash/block/token search and recent search behavior remain intact. URL activation does not insert cross-network identifiers into the existing network-unaware recent-search schema.
5. /search?q= accepts the same valid URLs and redirects to the same trusted target. Malformed or unsupported input follows existing search behavior without throwing a parser exception. No browser APIs in the parser; server and client agree.
6. Pure parser tests cover boundaries/host confusion/URL escapes/network distinctions. Actual running browser tests cover accepted URL suggestion, Enter/click/submit, rapid replacement/stale data, raw regression, and invalid destination rejection at desktop/mobile sizes. Capture before/after evidence. Full baseline checks and independent verify/audit required.
7. Publish one PR, run cyclops-audit fast; repair actionable findings, repeat verification/audit/publication and fresh Cyclops review. Current-head CI/review completion required. Never merge/deploy.
Scope excludes importing arbitrary third-party explorers, pasting list-page URLs, schema migration for URL recents, new dependencies, and Antithesis hosted campaigns (deterministic parser + browser checks are proportionate).
