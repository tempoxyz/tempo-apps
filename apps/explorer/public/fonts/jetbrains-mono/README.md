# JetBrains Mono

JetBrains Mono Regular (weight 400) matches Tempo Design System’s bundled face in
[`tempoxyz/ds`](https://github.com/tempoxyz/ds/blob/main/src/fonts/README.md).
It is the unmodified WOFF2 from [JetBrains Mono v2.304](https://github.com/JetBrains/JetBrainsMono/tree/v2.304/fonts/webfonts).

SHA-256: `a9cb1cd82332b23a47e3a1239d25d13c86d16c4220695e34b243effa999f45f2`.
