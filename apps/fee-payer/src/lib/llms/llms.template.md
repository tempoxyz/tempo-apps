# Tempo Fee Payer

> Sponsors transaction fees on the Tempo blockchain. Send a Tempo transaction that requests a fee payer, and the sponsor signs it as fee payer and pays its fees in PathUSD.

For a full reference, see [`/llms-full.txt`](/llms-full.txt).

## Networks

| Network | URL | Chain ID |
| --- | --- | --- |
| mainnet | https://sponsor.tempo.xyz | 4217 |
| moderato | https://sponsor.testnet.tempo.xyz, https://sponsor.moderato.tempo.xyz | 42431 |
| devnet | https://sponsor.devnet.tempo.xyz | 31318 |

Mainnet requires an API key in the path, as `/{key}`.
